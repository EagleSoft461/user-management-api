# v1.1.0 Development Progress

## Overview
This document tracks the progress of v1.1.0 features as outlined in the ROADMAP.

## Completed Features ✅

### 1. Change Password (2026-03-08)

**Status:** ✅ Complete

**Implementation Details:**
- Created `ChangePasswordRequest` DTO with validation
  - Current password (required)
  - New password (required, min 6 characters)
  - Confirm password (required)
  
- Added `changePassword()` method to `UserService`
  - Validates password match (new vs confirm)
  - Validates new password differs from current
  - Verifies current password with BCrypt
  - Encrypts and saves new password
  
- Created REST endpoint: `POST /api/users/change-password`
  - Requires JWT authentication
  - Extracts user from SecurityContext
  - Returns success message
  
- Added comprehensive unit tests (5 new tests)
  - Success scenario
  - Password mismatch validation
  - Same password validation
  - Incorrect current password
  - User not found scenario

**Files Modified:**
- `src/main/java/com/backend/usermanagement/dto/request/ChangePasswordRequest.java` (new)
- `src/main/java/com/backend/usermanagement/service/UserService.java`
- `src/main/java/com/backend/usermanagement/controller/UserController.java`
- `src/test/java/com/backend/usermanagement/service/UserServiceTest.java`

**Test Results:**
- All 9 unit tests passing
- Code compiles successfully
- Ready for manual testing
